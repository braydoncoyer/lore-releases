Added

  • Lore now runs natively on Apple Vision Pro. The spatial app brings the writing experience, sidebar navigation, All Notes, Nearby Notes, command palette, keyboard commands, and voice dictation into visionOS with platform-native controls.
  • Horizontal rules are available across every editor. Insert a standard Markdown divider from the slash menu, formatting controls, or menu commands. Lore renders it as a clean visual break while preserving ---, ***, or ___ in the Markdown file.
  • The command palette can create today’s daily note. Search for “today” when its note does not exist and the first result offers to create and open it. Historical and future date searches remain navigation-only.
  • iCloud conflicts are visible and recoverable. When two devices produce competing versions of a note, Lore now preserves both, lets you choose the version to keep, and can save either version as a separate Markdown note.

Changed

  • Notes now use a calmer editorial type system. Notes pair a New York serif title with system sans-serif body text and section headings, softer body ink, a narrower reading measure, and more deliberate paragraph rhythm. Titles now flow directly into the body without a divider, and the old font-family picker has been retired so every note keeps this hierarchy.
  • Uncreated wiki links are easier to spot. A [[link]] to a note that does not exist yet uses the normal link blue at reduced opacity. It remains clickable and becomes fully opaque automatically after the note is created.
  • All Notes is now a full library view. Browse notes as spacious preview cards or a compact list, group them by recency or title, filter by note type or tag, and sort by when they were edited, created, or by title. A new selection mode also supports bulk tagging, pinning, AI controls, and deletion.

Fixed

  • All Notes stays smooth in larger vaults. Scrolling now keeps only the necessary cards or rows active, reuses note preview details, and avoids continuous position tracking. Switching between grid and list view also keeps the page anchored instead of jumping. (Mac and iPad)
  • Cross-device edits arrive more reliably while a note stays open. Lore now reacts to precise iCloud file notifications, keeps changes that arrive during an in-progress refresh, retries notes that have not finished downloading, and safely restarts sync monitoring when iPhone or iPad returns to the foreground. Coordinated file work remains off the main thread so syncing does not interrupt typing. (Mac, iPhone, and iPad)
