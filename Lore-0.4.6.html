Added

  • Unlinked mentions reveal connections already present in your prose. The context panel now groups notes that mention the current note by title, shows the surrounding passage, opens directly at the mention, and can turn one occurrence into a wiki link without changing its visible wording.
  • Daily notes can be created for any date. Use the new calendar beside Daily, or search for a date such as “yesterday” in the command palette. The calendar marks days that already have an entry; double-click any day to open it immediately or create its note when one does not exist.
  • More Markdown blocks are available from the slash menu. Type / to insert code blocks, tables, callouts, footnotes, or headings through level six. The menu starts with a short list of common choices and searches every available block as you type. These commands are also available from the Mac and iPad menu bars.
  • Markdown from other writing apps renders more faithfully. Lore now understands underscore emphasis, 1) numbered lists, tilde and longer code fences, multi-backtick inline code, reference links, titled links, autolinks, Setext headings, and indented code blocks without rewriting the source file.

Fixed

  • Word selection keeps working in compact Mac windows. Closing the context panel or sidebar no longer leaves an invisible hit area over the page, so double-clicking words near either edge selects them normally.
  • Nested numbered lists resume the correct sequence. Indenting starts a nested sequence at 1, and returning or outdenting to the parent continues from the last parent item instead of counting nested items as parent items.
